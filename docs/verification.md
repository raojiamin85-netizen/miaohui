## 0. 本版改了什么

V0.16 里「把长说明收进可展开的 `说明` 按钮」那一版**没有上线，被否掉了**。本版按反馈重做：

| 问题 | 处理 |
|---|---|
| 页面上长灰字太多，用户「分不清该点哪里」 | 三句长说明不再摊在页面上，改成一个**品牌小人 + 叹号**的小图标（放在上一行末尾），鼠标悬停 / 键盘 Tab / 点按都能翻出气泡；点别处或 Esc 关掉 |
| 手绘波浪线出现位置不固定、显得杂乱 | 波浪线收敛到 **01 / 02 / 03 / 04 四个编号块的末尾各一条**（本版补齐了 02 末尾缺的那条）；候选之间、重新生成那一行都改成 1px 细线 |
| 04 区那句「贴几条你平时发的消息…」被混在长句里 | 拆成两句：语气那句**留在页面上**、正好在风格输入框上一行（就是「一行一条，例如…」的前面）；「默认只存在你自己的浏览器里…」那句收进图标气泡 |
| 作者看不到「有没有人在用」 | 沿用 V0.16 的方案 A：**只写不读**的匿名事件表 `events`（本版未改） |

## 本版仍未覆盖的部分（诚实清单）

- **真机上的上传截图**：移动端回归跑的是 Chromium + iPhone 仿真 + 真实触摸事件，本机没有 WebKit / 真机。不过这一条**已由使用者在自己手机上复点确认可用**（2026-10-16）。
- **真机上的提示图标**（本版新增的交互）：桌面 / 移动端两档都是仿真跑通（含 `hasTouch` + `tap()`），**真机上点一下是否好点、气泡位置是否合适，建议自己复点一次**。
- **iOS「添加到主屏幕」的最终效果**：线上 `manifest.webmanifest` 与三个图标均已确认 HTTP 200，入口在 iOS Safari 的**分享**菜单里（不在浏览器菜单里）；仍建议真机复点一次。
- **生成质量的大样本评测**：目前只有自评与少量真实使用反馈，50 条测试集的"像人评分"盲评**尚未完成**，这是下一步最该补的。埋点能回答「用了没有、等了多久」，但**回答不了「回得好不好」**。
- **埋点只统计"次数"，统计不到"人数"**：因为没有跨天可识别的标识（刻意的）。要看「有多少人、会不会回来」，需要再加一个匿名随机标识——要不要加是个取舍，目前选择不加。
- **「还没有档案」那句提示现在只在图标里**：空档案时，新用户要点一下图标才看得到「怎么存第一个档案」。按钮「＋ 存为档案」本身还在页面上，但这句话的可见性确实降低了——是个权衡，需要真实用户反馈来判。
